# Лабораторные работы по робастной статистике

## Лабораторная работа №1

Робастные оценки сдвига и масштаба в модели $X_i = \mu + \sigma U_i$, $F_U = 0.9 \Phi + 0.1 C(0, 1)$: MADN, IQRN, M-оценки масштаба, M-оценки сдвига (Хьюбер, bisquare, Хампель, Эндрюс, Уэлш), совместное оценивание, асимптотические дисперсии и моделирование.

Отчёт: [`lab1.ipynb`](lab1.ipynb).

## Лабораторная работа №2

Функции влияния и gross-error sensitivity оценок сдвига логистического закона (среднее, медиана, усечённое среднее, Ходжес–Леман, ОМП, Хьюбер, bisquare), проверка $v^2 = \mathbb E_F \mathrm{IF}^2$; точка срыва и информативность оценки Ходжеса–Лемана; M-оценки сдвига нормального закона с масштабом MAD: подбор констант по эффективности, максимальное и асимптотическое смещение, асимптотические дисперсии при законе Коши.

Отчёт: [`lab2.ipynb`](lab2.ipynb).

## Запуск

```bash
uv run jupyter execute --inplace lab1.ipynb
uv run jupyter execute --inplace lab2.ipynb
```

При первом запуске `uv` сам создаст окружение и установит зависимости.
