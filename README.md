# Лабораторная работа №1

Робастные оценки сдвига и масштаба в модели $X_i = \mu + \sigma U_i$, $F_U = 0.9 \Phi + 0.1 C(0, 1)$: MADN, IQRN, M-оценки масштаба, M-оценки сдвига (Хьюбер, bisquare, Хампель, Эндрюс, Уэлш), совместное оценивание, асимптотические дисперсии и моделирование.

Отчёт: [`lab1.ipynb`](lab1.ipynb).

## Запуск

```bash
uv run jupyter execute --inplace lab1.ipynb
```

При первом запуске `uv` сам создаст окружение и установит зависимости.
